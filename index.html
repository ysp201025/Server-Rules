စည်းကမ်းချက်များ

အားလုံး ပျော်ရွှင်စွာ ကစားနိုင်ရန်အတွက်

mic Voice Chat: Telegram မှတစ်ဆင့် အသံပြောဆိုနိုင်ပါသည်။ Telegram Voice Chat သို့ဝင်ရန်

gavel 1. အခြေခံစည်းကမ်းများ

check_circle အားလုံးကို လေးစားပါ။ အခြားသူများကို စော်ကားခြင်း၊ နှောင့်ယှက်ခြင်းမပြုရ။ Warning → Kick
block Hack / Cheat / X-ray သုံးစွဲခြင်း လုံးဝခွင့်မပြုပါ။ Permanent Ban
volume_up Discord And Telegram Voice Chat တွင် အော်ဟစ်ခြင်း၊ ဆူညံခြင်းမပြုရ။ Mute 1 hour
badge ထိုးထွင်းသော / မသင့်လျော်သော username သို့မဟုတ် skin မသုံးရ။ Request change

home 2. ဆောက်လုပ်ခြင်းနှင့် နယ်မြေ

block အခြားသူ၏ အိမ် / နယ်မြေထဲသို့ ခွင့်မပြုဘဲ မဝင်ရ။ (Griefing တားမြစ်သည်) Ban 3 days
explosion TNT, Lava, Water ကို အခြားသူများ၏ နေရာတွင် ဖျက်ဆီးရန် အသုံးမပြုရ။ Ban 1 week
forest သစ်ပင်များ အလွန်အကျွံခုတ်ခြင်း (ပြန်မစိုက်ခြင်း) မပြုရ။ Warning

swords 3. PvP နှင့် ပြိုင်ဆိုင်မှု

air PvP ကို သဘောတူညီမှုမရှိဘဲ မစတင်ရ။ (သေစေနိုင်သော တိုက်ခိုက်မှု) Kick + Warning
place Spawn area အနီးတွင် PvP လုံးဝခွင့်မပြုပါ။ Ban 1 day
inventory_2 သေဆုံးသွားသူ၏ item များကို ခွင့်မပြုဘဲ ယူငင်ခြင်းမပြုရ။ Return item + warning

paid 4. စီးပွားရေးနှင့် စနစ်

warning ဈေးကွက်ထဲတွင် ဈေးအတက်အကျ လိမ်လည်ခြင်း (Scam) မပြုရ။ Ban 2 days + ပစ္စည်းသိမ်း
timer အလွန်အကျွံ ကုန်သွယ်ခြင်း (AFK farming) ခွင့်မပြုပါ။ Kick + Warning

စည်းကမ်းချက်များကို လိုက်နာရန် ပျက်ကွက်ပါက အထက်ပါ အရေးယူမှုများ ခံရနိုင်ပါသည်။

ကျေးဇူးပြု၍ အားလုံး ပျော်ရွှင်စွာ ကစားကြပါစို့။ 🎮
